# EAA-Scan

Automated WCAG 2.1 AA website accessibility scans for the European Accessibility Act, with fixes that are verified on your live page.

Site: https://hanru269.github.io/eaa-scan/ - Services: https://croucamp.gumroad.com/l/accessibility-scan and https://croucamp.gumroad.com/l/accessibility-scan-fixes

**About the scan bot (`EAA-Scan/1.0`):** it loads one public page like a browser and runs axe-core; it does not crawl, log in or store content, and it skips sites whose robots.txt disallows automation. To be excluded, open an issue naming your domain.

Automated scans are not legal advice and not a compliance certificate.
